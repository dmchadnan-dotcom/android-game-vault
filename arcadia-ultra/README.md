# Arcadia Ultra

Three original offline HTML Canvas arcade games in one Android project: Hyperlane Drift (traffic racer), Starfall Defender (space shooter), and Aegis Towers (tower defense). No login or network permission required.

Run **index.html** in Chrome, or open **android-studio** with Android Studio, Java 17, Android API 36, Gradle 8.13. Build with `gradle :app:assembleDebug :app:bundleRelease`.

Includes pause, touch controls, saved best scores in localStorage, and 10 tower-defense waves. Current release candidate is not production-signed or approved by Google Play. See the downloadable Complete Game Pack for gameplay tests, actual screenshots, privacy policy draft, and publishing checklist.

Before release: QA on real Android phones, app name/package clearance, final publisher privacy contact and Play Console declarations, securely signed AAB and Play Store approval.
