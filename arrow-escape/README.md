# Arrow Escape — Beyond the Grid

Original offline single-player mobile puzzle with 300 levels and daily challenge. Hints, lives, timer, undo, coins, progress in localStorage. Android API 26+, target SDK 36, no INTERNET permission or ads/tracking. CI builds a debug APK and unsigned release AAB. Test on physical phones before production.
