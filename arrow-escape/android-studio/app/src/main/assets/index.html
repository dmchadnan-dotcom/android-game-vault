The essentials

How to play

Three rules, endless possibilities.

↗

1. Follow the arrows

Every arrow is made of a continuous path with a direction at the tip. Tap the path to move it forward.

⛔

2. Find the free path

An arrow can leave only when there is no other arrow between its tip and the edge of the board. A blocked attempt costs a heart.

✦

3. Clear the board

Remove every arrow to win. Use a hint if stuck. Earn coins and stars, and unlock harder puzzles.
