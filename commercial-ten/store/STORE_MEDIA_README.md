# Tenfold Arcade — Store Media
This folder contains SVG **design source** for the app icon and feature graphic.
Google Play requires exported raster assets: 512×512 PNG icon and 1024×500 PNG/JPEG feature graphic.

The complete downloadable Play Store preparation kit in the ChatGPT conversation includes those raster exports and actual browser gameplay screenshots. Those binary assets were not transferred to this GitHub repository automatically. Upload genuine screenshots to Play Console only after validating the Android build on a device, and never substitute conceptual artwork for screenshots of gameplay.

File names in the kit:
- `store/icon_512.png`
- `store/feature_graphic_1024x500.png`
- `store/play_screenshot_1.png` through `play_screenshot_4.png`
- Additional QA screenshots and previews

Before publication: verify final title, visual asset ownership, published privacy-policy URL, account declarations, Play App Signing, signed release AAB, accessibility, support email, testing requirements, and phone performance.
