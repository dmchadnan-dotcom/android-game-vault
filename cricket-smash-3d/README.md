# Cricket Smash 3D — Stadium Edition

Offline original cricket arcade game. Browser and Android asset versions share the same exact self-contained HTML.

Modes: Quick Match (12 balls), Super Over (six balls), Career Tour (30 levels), Daily Challenge and Practice Nets. Includes difficulty selection, direction and loft controls, wickets, scores and stored progress.

The graphical stadium is a custom perspective-rendered 3D-style (2.5D) scene, **not a true WebGL 3D stadium**. No network, ads or purchases.

Android: API 36, Android 8+, Gradle 8.13, AGP 8.13.2, Java 17. Open android-studio in Android Studio. Build debug APK using `gradle :app:assembleDebug`, unsigned AAB with `gradle :app:bundleRelease`.

Before Play Store: real phone testing, signed bundle/secure keystore, publisher identity/privacy URL, original brand checks, content rating/data safety declarations and Play Console review. Do not distribute debug APK as a production release.
