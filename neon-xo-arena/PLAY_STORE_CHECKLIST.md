# Google Play release checklist
- [x] Original offline browser game, mobile UI, Android source
- [x] Target SDK 36, min SDK 26
- [ ] Physical Android device testing
- [ ] Production signing key and signed release AAB
- [ ] Verify applicationId uniqueness and publisher name
- [ ] Host publisher-specific privacy policy
- [ ] Complete Play Console data safety, content rating and screenshots
- [ ] Complete internal/closed testing as required
- [ ] Google Play review and publication
