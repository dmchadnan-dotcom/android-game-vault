# Neon XO Arena

Original offline mobile game with standalone HTML and Android Studio project. Open index.html in a browser. For Android, open android-studio in Android Studio (Java 17, Gradle 8.13, Android Gradle Plugin 8.13.2, compileSdk 36, minSdk 26), and run Gradle tasks :app:assembleDebug and :app:bundleRelease. APK is for local device testing. Release AAB requires a secure upload key and Play Console approvals. The game has no Internet permission and uses local device storage for scores and progress. Verify a unique applicationId before publishing.
