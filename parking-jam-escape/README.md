# Parking Jam Escape

Original offline mobile puzzle game. Browser source is bundled at `android-studio/app/src/main/assets/index.html`. Android Studio project is built with Java 17, AGP 8.13.2, Gradle 8.13, API 36, Android 8.0+. No internet permission.

Browser-playable version and original Play Store graphics are supplied separately in the completed game pack. The AAB is unsigned until publisher signing is configured. Device QA, store listing, privacy disclosures, and Play Console submission are pending.
