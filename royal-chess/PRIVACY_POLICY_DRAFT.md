Royal Chess Studio is currently a fully offline game. It does not request location, microphone, camera, contacts or Internet permissions; it uses no third-party ads or analytics SDK, and does not require user accounts. Preferences and game histories are saved locally using app WebView storage. We do not transmit these records to a server. Users can clear the app's data or uninstall it to remove saved records.

Publish an accurate public HTTPS version of this policy before release. Recheck data disclosure statements if future versions add SDKs, online features or ads.
