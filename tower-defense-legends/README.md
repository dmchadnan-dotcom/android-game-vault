# Tower Defense Legends: Citadel Rift

Original offline mobile tower-defense game. Four maps, 40 waves, five upgradeable towers, six enemy types and Endless Siege. Open `index.html` to play. Open `android-studio/` in Android Studio with JDK 17 and SDK 36. The GitHub workflow creates a debug APK and unsigned AAB. Release requires signing, device tests and Play Console review.
